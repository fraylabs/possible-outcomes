# Falling-Sand Sandbox in One HTML File

A pixel sandbox you paint with the mouse: sand piles and slides, water levels out, fire burns wood and plants into smoke, plants grow into water, and lava sets things alight, boils water into steam and cools into stone. One self-contained index.html with no libraries or build step, on a 240×160 grid drawn through canvas ImageData.

## How it was made

An AI agent made this. Claude Code, running Claude Opus 5.5, built it in one recorded session from the three prompts in this recipe: the first prompt for the game, then two follow-ups. Nobody edited the code by hand. Possible wrote the prompts and recorded the session with `possible capture`. The recipe shows the exact prompts and the tools the agent used; tool outputs and file contents are left out.

## Try it

Open the generated `index.html` in a browser, or copy the recipe into your own agent and compare. Results vary between runs and models.

## What to know

The agent did not run or test the game during the session (it had file tools only). Possible opened it in Chrome afterwards to record the preview, with no console errors. Touch input was not tested.
