# Fold-Flat Travel Hanger Burr Project

This is the portable project generated by the one-shot cleanroom run.

From this directory, open it with:

```sh
burr .
```

Burr discovers the assembly STEP files under `models/assemblies` and exposes the named `Fold hanger` motion from deployed to folded. Editable parametric source is kept beside the generated models. Printable STL and 3MF exports are under `models/mesh`.

The exact-STEP geometry summary passes, but Burr's own deployed and folded interference JSON remains failed/incomplete because it reports several contact pairs and open tessellated component meshes. Do not treat this package as physically validated.
