# What If Roblox Story Short

A 45-second vertical "What if" Short in the 2D kid-Roblox story style. Every frame is drawn in code on an HTML canvas, with a shared blocky character rig, punchy captions, fake game UI, voices and a rewind loop back to the first frame. No image or video model.

## Try it

Copy the prompt and run it with **Claude Opus** in a coding agent with a shell. It asks for your story idea (or pitches three) and shows you the script and shot list before any voice is generated. Everything is free except an optional ElevenLabs voice, at about US$0.15 a Short. The preview is the creator's actual output, not a Possible-generated substitute.

By [Finn](https://x.com/finnardley). [See the original post](https://x.com/finnardley/status/2117997239125585942). The copyable text is the prompt as posted, from `<inputs>` to `</start>`, with only the post's introduction removed.
