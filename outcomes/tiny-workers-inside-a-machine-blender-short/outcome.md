# Tiny Workers Inside a Machine (Blender Short)

A 35-45 second vertical 3D short about what's "really" happening inside an everyday machine. Someone presses the button on a printer, the camera dives inside to a tiny secret workshop, and a team of round capybara workers in little hats sketch the picture with a giant pen, paint it, hang it up to dry and push it out of the tray. Everything is built in Blender from Python code, with soft global illumination, shallow depth of field and slow camera moves.

## Try it

Copy the prompt and run it with **Claude**. It asks you for one everyday machine (a printer, a coffee machine, an ATM, a microwave) and a length from 35 to 45 seconds, or pitches three machines if you have no idea. It gives you back the full Blender Python script, a render settings checklist for your GPU and a shot list with timings. You run the script and render in Blender yourself. The story beats are written around a printer, so expect to adjust them for other machines.
