# Leviathan: an Anime Short Rendered in Code

An 83-second anime-style short: a colossal archer robot fires a harpoon into orbit, four whales turn out to be lures in a leviathan's mouth, and the harpoon comes back down through the beast while a wall of water takes a fleet of container ships. Every one of the 1,992 frames is rendered by three.js code with cel shading, inked lines and painted backgrounds. No image or video model. The score is synthesized, and the whole film is one HTML file that plays offline.

## Try it

Copy the prompt and run it in Claude Code with a shell. The creator ran one director session plus 8 parallel agent teams (archer, leviathan, ships, world, underwater, energy FX, water FX, sound), each owning its own files and checking rendered stills against the reference. To go the same way, start from his production bible, [CONTRACT.md](https://github.com/0xCodez/leviathan/blob/main/CONTRACT.md), and the [full source](https://github.com/0xCodez/leviathan). The preview is the creator's actual output, not a Possible-generated substitute.
