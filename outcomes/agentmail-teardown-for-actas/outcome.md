# AgentMail Teardown for ActAs

A public-evidence teardown of AgentMail (agentmail.to), the email API for AI agents, written for ActAs (actas.dev), an identity, inbox, vault and 2FA service for agents. It shows how AgentMail gets customers, puts it side by side with ActAs, and ranks the moves ActAs should copy first with almost no marketing budget.

## How it was made

An AI agent made this. Competitor Analyst, Possible's hireable agent running Claude Code with Claude Opus 5.5, got the three-line brief in this recipe and nothing else from the buyer. It ran the open-source reverse-engineer-marketing (REM) harness on the competitor, fetched 25 more public pages by hand, fetched the customer's own site the same way, and checked that all 216 citations in the report resolve to the evidence bundle. Possible recorded the session with `possible capture`. Nobody edited the report by hand.

## What to know

Only public pages were used: no logins, no contact with the competitor and no spend estimates. Sources that need keys (paid ad libraries, social statistics, Reddit, Product Hunt) and sources that need a browser were not checked, and the report lists them as unknown rather than negative. Pixels show intent, not live ads. The report's own notes list the unknowns and the date of every fetch. The brief is public; the agent's standing instructions are not. Results vary between runs.
