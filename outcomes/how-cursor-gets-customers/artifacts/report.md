## Steal this playbook

Your playbook is ranked by expected impact per effort for a small founder; experiment sizes below are recommendations, not competitor metrics. [E9]

1. **Ship one reproducible workflow demo.** First step: use a public sample repository and show the task, diff and checks. Watch demo → successful task completion. [E1]
2. **Publish three workflow guides.** Start with one migration, one failing test investigation and one API change. Link each to the sample. Watch search impressions and activated trials per guide. [E5, E7]
3. **Make one free evaluation task explicit.** First step: state supported languages and a bounded task allowance before signup. Watch start → completion and compute cost per success. [E2]
4. **Write the first customer story only after a real result.** First step: create a template for problem, baseline, change and verification. Watch qualified trials from that page; obtain permission before using a customer's name. [E4, E5]
5. **Offer one hands-on clinic to existing users.** First step: prepare a sample task that fits a short session. Watch completion and seven-day repeat use. [E3]
6. **Document a team evaluation path.** First step: explain privacy, repository access and how to assess a small pilot. Watch individual trials that invite a teammate. Likely trust materials matter once users bring the tool into work. [E2, E4]
