# Seven-Inch Digital Photo Frame Burr Project

This is the portable CAD and KiCad project generated by the one-shot cleanroom run.

From this directory, open the mechanical models and named stand motion with:

```sh
burr .
```

The editable mechanical source is under `models/cad/source`; generated part and assembly exports are under `models/cad/parts` and `models/assembly/exports`. The KiCad project is under `models/kicad/source`, with the schematic PDF and BOM under `models/kicad/exports`.

This project is incomplete and repair-required. ERC passes, but DRC/parity fails, so there is no populated PCB STEP or fabrication output. The mechanical assembly uses a clearly named conservative PCB envelope. Burr's integrated checks also remain failed/incomplete.
