# Claude Skills, Explained in 50 Seconds

A 50-second lecture-style explainer reel: a lip-synced cartoon teacher, slides and a typing terminal that land on the spoken word, captions that build, and a loop back to the first frame.

## Try it

Download the free guide from [Theo's page](https://theoxmotion.blue-hippodraco.workers.dev/r/explainer-reel-studio/), or copy the prompt here (it's the guide's `explainer_prompt.md`). Save it as `CLAUDE.md` in an empty folder, open Claude Code there and say "make a reel". The preview is the creator's own example, not a Possible-generated substitute.
