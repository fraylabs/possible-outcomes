# Flow-Field Poster Maker

Thousands of particles follow a smooth noise field and leave thin translucent trails that build up into ink-like posters in A-series proportions. Six palettes (paper and ink, risograph, ocean, sunset, mono, neon), sliders for particle count, noise scale, swirl and line width, and a contact sheet of nine random seeds you can click to open. Every poster is reproducible from its URL, and the PNG export renders at 3x. One self-contained index.html with hand-written noise and no libraries.

## How it was made

An AI agent made this. Claude Code, running Claude Opus 5.5, built it in one recorded session from the two prompts in this recipe. Nobody edited the code by hand. Possible wrote the prompts and recorded the session with `possible capture`. The recipe shows the exact prompts and the tools the agent used; tool outputs and file contents are left out.

## Try it

Open the generated `index.html` in a browser, or copy the recipe into your own agent and compare. Results vary between runs and models.

## What to know

The agent did not run or test the page during the session (it had file tools only). Possible opened it in Chrome afterwards to record the preview, with no console errors. PNG export and the shareable URL were not checked in the recording.
